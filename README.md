# ckmah/skills

Personal agent skills sync for Cursor and Claude Code. Hands-free across machines.

## Prerequisites

- **Node.js 18+** — runs the CLI (`node`, `npm`, `npx`)
- **Git** — clone, commit, push to GitHub
- **Cursor** — primary agent; optional [hooks](https://cursor.com/docs/agent/hooks) enable sync-on-open and terminal safety net
- **Claude Code** — receives the same global skills via `npx skills -a claude-code` (no extra setup beyond having it installed)
- **GitHub access** — SSH key or HTTPS credentials for push

## Setup (once per machine)

    npx github:ckmah/skills setup

## Commands

| Command | Purpose |
|---------|---------|
| `setup` | One-time machine bootstrap (clone, install, scheduler, hooks) |
| `install` | Install all skills from manifest |
| `add <repo> [--skill name]` | Install skill, update manifest, push to GitHub |
| `remove <skill>` | Remove skill, update manifest, push |
| `sync` | Pull from GitHub and install delta |
| `update` | Update registry skills and push manifest if changed |
| `check` | Show available skill updates |
| `watch` | Poll GitHub on an interval (alternative to OS scheduler) |

Background sync runs every 15 minutes and when Cursor opens (if hooks are installed).

## Development

    npm test
    npm run test:watch
